# Airline Ticket Reservation and Management System

A full-stack airline reservation platform: Spring Boot backend, React frontend.

## Structure

    airline-reservation-platform/
    ├── backend/    Spring Boot REST API (auth, flights, bookings, cancellations)
    └── frontend/   React (Vite) app, "Skyfare"

## Running it

See backend/README.md and frontend/README.md for setup details. In short: run the
backend on :8080, then the frontend on :5173. CORS is already configured for that pairing.
